# Module pages pédagogiques

`Comparison` lance un Worker indépendant pour les trois consensus à 7 nœuds honnêtes, capture les conditions et affiche tableau, diagramme sélectionnable, conclusion calculée et cas d’usage contextualisés. Les résultats restent montés pendant la navigation et ne sont pas réétiquetés après changement du laboratoire. Un export fournit leurs configurations complètes.

`Learn` expose les notions nécessaires au jury : nœuds, création des blocs, fourches, réorganisations, double dépense, seuils et limites. Il décrit le code appliqué, sans assimiler ce modèle à des implémentations intégrales de Bitcoin ou Ethereum.

Lors d’une modification, vérifier unités, résultats non atteints, charge offerte, terminaison, cohérence des interprétations, affichage mobile et références.

Fusion 4 : Blockchain prépare le rapport canonique, connecte MetaMask Sepolia, déploie le registre, ancre puis vérifie sans portefeuille via RPC. Aucune réussite sans reçu confirmé. Voir docs/SEPOLIA.md.
